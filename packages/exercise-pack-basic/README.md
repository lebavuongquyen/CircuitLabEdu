# @circuitlabedu/exercise-pack-basic

A bilingual Vietnamese/English sample curriculum for CircuitLabEdu. This package owns lesson definitions, schema validation and assessment rules; it does not render UI.

```js
import { lessons, validateLesson, assessCircuit } from "@circuitlabedu/exercise-pack-basic";
```

See [EXERCISE_PACK_AUTHORING.md](./EXERCISE_PACK_AUTHORING.md) for the complete authoring contract, examples, validation process and release checklist.
